Layout A · Node graph

n8n-style canvas. Raw ingredients are nodes wired into sub-assemblies, which are wired into the final product.

  • Drag ingredients in and wire them together
  • Amounts are edited where each wire lands
  • Click a node to light up everything that feeds it

Layout B · Linked recipe cards

Modernist Cuisine-style recipe cards. The final recipe is the main card, and each sub-recipe row links to its own card.

  • Reads like a recipe book: weights, procedure, notes
  • "see recipe →" jumps to the sub-recipe card
  • Structure tree and draggable ingredient library

Layout C · Recipe sheets

Modernist Cuisine-style recipe sheets. Ingredient groups sit beside the procedure steps that use them, and connectors link each sub-recipe to its own sheet.

  • Yield, time, storage, difficulty, requirements
  • Weight · volume · scaling (100% base) · procedure
